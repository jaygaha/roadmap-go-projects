# Advanced Projects

This directory contains advanced backend projects that demonstrate complex concepts and production-ready patterns in Go.

## Projects

- [Database Backup Utility](./database-backup-utility/README.md)
  - A comprehensive CLI tool for backing up and restoring multiple database types (MySQL, PostgreSQL, MongoDB, SQLite) with cloud storage support, compression, incremental backups, and automated scheduling.
  - [Challenge Details](https://roadmap.sh/projects/database-backup-utility)
- [Real-time Leaderboard System](./realtime-leaderboard-system/README.md)
  - A real-time leaderboard system for ranking and scoring users across various games/activities, powered by Redis sorted sets.
  - [Challenge Details](https://roadmap.sh/projects/realtime-leaderboard-system)
